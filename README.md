# Miheer Nayak — Personal Portfolio

**Live site:** [miheernayak17.github.io](https://miheernayak17.github.io)

Personal digital portfolio of Miheer Nayak — first-year B.Tech Computer Science Engineering student at Karnavati University, Gandhinagar.

Built as **Mini Project 2: AI Portfolio and Presentation (10B)** — hand-coded in HTML, CSS and vanilla JavaScript, with AI tools used for drafting and review (documented on the site itself).

## Tech

- **HTML5** — semantic structure
- **CSS3** — custom design system, CSS Grid, `clamp()` fluid type, mask-image photo blend
- **Vanilla JavaScript** — scroll reveals (IntersectionObserver), animated skill meters, scroll-spy nav, smooth anchor scrolling, copy-to-clipboard
- **No frameworks, no build step, no templates** — a single `index.html` plus one image

## Design

Midnight `#070A10` + electric teal `#2FE3C0`, with amber accents.
Display type: *Instrument Serif*. Body: *Inter*. Mono: *JetBrains Mono*.
